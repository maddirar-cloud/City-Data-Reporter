**Description**
City Data Reporter is a python program that retrieves weather data from different cities using the OpenWeather API.

The program asks for a city name, retrieves the weather data, and displays the results, and then saves the information to city_data.csv, and reports saved cities and their conditions.

**Features**
Validates city name isn't empty
Displays:
1. Name
2. Country code
3. Temperature in celcius
4. Humidity percentage
5. Weather description
6. CSV saving mechanism
7. Reads CSV data
8. Error handling and API key errors
**How to Run**
py reporter.py

OR

open file, and click run on your preferred code editor

**Requirements**
Python 3
OpenWeatherMap API KEY
Python 'requests' library
